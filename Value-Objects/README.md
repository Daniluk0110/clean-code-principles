# Value Objects 💎

Объекты-значения — это небольшие объекты, идентичность которых определяется не уникальным ID, а их состоянием.

## Преимущества
- **Типизация:** Вместо `string` мы передаем `Email`.
- **Валидация:** Объект всегда находится в валидном состоянии.
- **Иммутабельность:** Состояние объекта нельзя изменить после создания.
- **Бизнес-логика:** Инкапсуляция логики внутри объекта.

## Список примеров

В папке [`Examples/`](Examples/) вы найдете практические примеры:

- [**Email**](Examples/Email/Email.php) — валидация адреса.
- [**Money**](Examples/Money/Money.php) — операции с валютами и защита от сложения разных валют.
- [**Coordinate**](Examples/Coordinate/Coordinate.php) — точка на карте (широта, долгота) с валидацией диапазонов.
- [**DateRange**](Examples/DateRange/DateRange.php) — период между датами, проверка вхождения даты в период.
- [**Weight**](Examples/Weight/Weight.php) — физический вес с поддержкой единиц измерения (кг, г, фунты).
- [**Volume**](Examples/Volume/Volume.php) — физический объем с поддержкой единиц измерения (литры, галлоны).
- [**Password**](Examples/Password/Password.php) — инкапсуляция сложности пароля и его хеширования.
- [**Percentage**](Examples/Percentage/) — валидация процентов (от 0 до 100) и удобная конвертация в десятичные дроби.
- [**VatNumber**](Examples/VatNumber/) — инкапсуляция формата налогового номера (ИНН/VAT).

## Правила Value Objects
1. **Immutable** — не имейте сеттеров. Любое изменение возвращает НОВЫЙ объект.
2. **Equality** — сравнение идет по значениям полей, а не по ссылке.
3. **Always Valid** — объект не может быть создан в невалидном состоянии (валидация в конструкторе).
