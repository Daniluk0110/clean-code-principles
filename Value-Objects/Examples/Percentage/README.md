# Percentage (Процент) 💯

Использование примитивных типов (`int` или `float`) для представления процентов часто приводит к ошибкам. Программист может забыть, в каком формате передаются данные: `50` (как 50%) или `0.5` (как 50%)? А можно ли передать `-10` или `150` в качестве скидки?

## ❌ Проблема (`bad.php`)
При использовании `float $discount` нет никакой гарантии, что значение находится в допустимых пределах (от 0 до 100). Бизнес-логике приходится постоянно проверять значения перед расчетами.

## ✅ Решение (`good.php`)
Создание Value Object `Percentage`. Он инкапсулирует в себе:
- Валидацию: нельзя создать процент меньше 0 и больше 100.
- Состояние: всегда понятно, какое значение внутри.
- Поведение: класс может сам переводить значение в десятичную дробь для умножения (например, `50` -> `0.5`), избавляя от путаницы при расчетах.
