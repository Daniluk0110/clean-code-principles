# Vat Number (ИНН / Налоговый номер) 🏛️

Налоговые номера (VAT, ИНН) — это не просто строки. Они имеют специфический формат, длину и иногда контрольные суммы.

## ❌ Проблема (`bad.php`)
Передавая налоговый номер как `string $vatNumber`, мы допускаем возможность сохранения пустой строки, произвольного текста или номера неверного формата в базу данных. Вся валидация ложится на контроллеры или сервисы, что приводит к дублированию кода (Code Smell: DRY).

## ✅ Решение (`good.php`)
Обернуть налоговый номер в Value Object `VatNumber`. Как только объект создан — вы на 100% уверены, что номер синтаксически корректен. И этот объект можно смело передавать в API сторонних сервисов без дополнительных проверок.
