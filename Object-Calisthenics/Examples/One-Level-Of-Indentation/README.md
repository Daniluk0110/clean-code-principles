# One Level Of Indentation (Один уровень вложенности) 📉

Правило объектной калистеники гласит: **«Только один уровень отступа на метод»**. Это означает, что внутри метода не должно быть вложенных управляющих структур (например, `if` внутри `foreach`, или `if` внутри `if`).

## ❌ Проблема (`bad.php`)
Сложные методы с глубокой вложенностью очень трудно читать и тестировать. Если у вас есть цикл, внутри него проверка, а внутри проверки еще одна проверка, метод пытается делать слишком много вещей одновременно. Цикломатическая сложность взлетает до небес.

## ✅ Решение (`good.php`)
Применяйте рефакторинг **Extract Method (Выделение метода)**. Тело цикла или внутреннее условие можно вынести в отдельный приватный метод с понятным названием. Это делает код плоским, самодокументируемым и легко тестируемым (если метод публичный в другом классе).
