# KISS (Keep It Simple, Stupid) 🧩

Делайте код как можно проще. Не усложняйте решение там, где это не требуется.

## Список примеров

- [**Api Url Builder**](Examples/ApiUrlBuilder/) — простой способ сборки URL против переусложненных "пайплайнов".
- [**Date Formatting**](Examples/DateFormatting/) — использование стандартных функций вместо кастомных велосипедов.

## Как следовать KISS?
1. Не используйте паттерны проектирования там, где достаточно обычного `if`.
2. Избегайте преждевременной абстракции.
3. Используйте возможности языка и стандартных библиотек.
4. Если код можно прочитать и понять за минуту — это хороший код.
