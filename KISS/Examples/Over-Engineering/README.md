# Over-Engineering (Переинженеринг) 🏗️

Этот пример демонстрирует нарушение KISS через чрезмерное использование паттернов проектирования там, где они не нужны. 

## ❌ Проблема (`bad.php`)
Разработчик решил получить простую конфигурацию из массива, но создал для этого `ConfigurationInterface`, `ConfigurationFactory`, абстрактные классы и синглтоны. Код раздут, его сложно читать, а для добавления нового параметра нужно пробираться через горы абстракций. Это типичный Over-Engineering.

## ✅ Решение (`good.php`)
Для простых задач нужны простые решения. Если конфигурация — это просто массив, используйте простой класс `Config` с методом `get()`. Не добавляйте паттерны «на будущее» (тут также пересекается с YAGNI), пока реальная бизнес-необходимость этого не потребует.
