# Domain Exceptions (Доменные исключения) ⛔

Вместо выбрасывания стандартных исключений (например, `Exception` или `InvalidArgumentException`) с текстовыми сообщениями, в ООП-коде принято использовать типизированные кастомные исключения.

## ❌ Проблема (`bad.php`)
Когда мы выбрасываем стандартный `\Exception('Недостаточно средств')`, на уровне контроллера мы не можем понять, **какая именно** произошла ошибка, не парся текст сообщения. Это делает обработку ошибок хрупкой: если текст изменится, обработчик сломается.

## ✅ Решение (`good.php`)
Создавать классы исключений, специфичные для предметной области (Доменные исключения). Например, `InsufficientFundsException`. На уровне инфраструктуры (контроллера) мы можем отлавливать конкретно этот тип и переводить его в понятный клиенту статус (например, HTTP 422), оставляя все остальные `\Exception` как HTTP 500 (серверная ошибка).
