# Error Handling 🛡️

Обработка ошибок — это критическая часть чистого кода. То, как программа реагирует на внештатные ситуации, определяет её стабильность и удобство отладки.

## Основные принципы

### 1. Используйте исключения вместо возврата специальных значений
Возврат `null`, `false` или `-1` заставляет вызывающий код постоянно проверять результат. Исключения позволяют отделить логику обработки ошибок от основной бизнес-логики.

### 2. Создавайте специфичные исключения
Вместо базового `\Exception`, создавайте свои классы (например, `UserNotFoundException`). Это позволяет ловить конкретные типы ошибок и реагировать на них по-разному.

### 3. Не игнорируйте пойманные исключения
Пустой блок `catch` — это «черная дыра», которая прячет баги. Если вы поймали ошибку, вы должны либо обработать её, либо залогировать, либо пробросить дальше.

### 4. Используйте паттерн Result для ожидаемых ошибок
Если ошибка является частью нормального флоу (например, валидация формы), использование исключений может быть избыточным. В таких случаях объект-результат (`Result`, `Either`) делает код более явным.
