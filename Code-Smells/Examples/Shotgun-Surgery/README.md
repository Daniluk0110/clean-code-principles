# Shotgun Surgery (Стрельба дробью) 💥

Этот запах кода возникает, когда при каждом небольшом изменении в системе (например, добавлении нового статуса) вам приходится вносить мелкие правки в огромное количество разных классов. 

## ❌ Проблема (`bad.php`)
Представьте, что мы добавляем новый статус заказа — `Refunded`. Нам придется:
1. Искать контроллер, чтобы добавить обработку.
2. Искать класс отправки писем, чтобы добавить новый шаблон.
3. Искать класс отчетов, чтобы задать цвет статуса.

Одно изменение "выстрелило дробью" по всей кодовой базе. Легко что-то забыть, и система сломается.

## ✅ Решение (`good.php`)
Инкапсулировать поведение внутри самих объектов (например, используя полиморфизм или паттерн State). Теперь, чтобы добавить новый статус `Refunded`, мы создадим **один новый класс** `RefundedStatus`, который будет реализовывать интерфейс `OrderStatus`. Нам больше не нужно искать по всей кодовой базе раскиданные операторы `if`!
