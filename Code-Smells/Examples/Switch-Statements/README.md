# Switch Statements (Одержимость switch/match) 🔀

Запах возникает, когда код изобилует сложными и гигантскими конструкциями `switch` или `match`, которые часто дублируются в разных местах приложения.

## ❌ Проблема (`bad.php`)
Каждый раз, когда в бизнес-логику добавляется новая курьерская служба, мы вынуждены модифицировать класс `ShippingCalculator`. Класс постоянно растет, нарушается принцип Открытости/Закрытости (OCP).

## ✅ Решение (`good.php`)
Заменить условные операторы на **Полиморфизм**, например, используя паттерн Стратегия (Strategy). Теперь каждая служба доставки — это отдельный класс со своей логикой. Для добавления новой службы мы создаем новый класс, не трогая старые.
