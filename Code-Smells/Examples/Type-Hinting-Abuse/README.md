# Type Hinting Abuse / Data Mappers (Одержимость массивами) 📦

Использование стандартных неструктурированных ассоциативных массивов для передачи данных между слоями приложения.

## ❌ Проблема (`bad.php`)
Когда метод принимает `array $userData`, программист не знает, какие ключи обязательны, а какие нет. IDE не может помочь с автодополнением (autocomplete). Приходится писать кучу `isset()` и гадать о структуре массива.

## ✅ Решение (`good.php`)
Использовать Data Transfer Objects (DTO) или строго типизированные классы. Объект гарантирует наличие полей, их типы, и делает код самодокументируемым. Проверки `isset` становятся не нужны — PHP сам проследит за типами.
