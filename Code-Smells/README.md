# Code Smells 🕵️‍♂️

Код, который «попахивает» — это не обязательно ошибка, но явный признак того, что код будет сложно поддерживать и развивать.

## Список примеров

В папке [`Examples/`](Examples/) вы найдете практические примеры типичных запахов кода:

- [**Primitive Obsession**](Examples/PrimitiveObsession.php) — использование примитивных типов (`string`, `int`) для хранения сложных данных (email, деньги, координаты).
- [**Data Clumps**](Examples/DataClumps.php) — группы данных, которые всегда передаются вместе (широта и долгота, начало и конец периода).
- [**God Object**](Examples/GodObject.php) — класс, который знает слишком много и делает слишком много.
- [**Long Method**](Examples/LongMethod.php) — метод, содержащий слишком много строк и выполняющий несколько разных задач.
- [**Large Class**](Examples/LargeClass.php) — класс с огромным количеством полей и методов, нарушающий SRP.
- [**Feature Envy**](Examples/FeatureEnvy.php) — метод, который больше интересуется данными другого класса, чем своего собственного.
- [**Inappropriate Intimacy**](Examples/InappropriateIntimacy.php) — излишне тесная связь между классами, когда один лезет во внутренности другого.
- [**Message Chains**](Examples/MessageChains.php) — длинные цепочки вызовов (A->B()->C()->D()), нарушающие закон Деметры.

## Как бороться?
Используйте рефакторинг:
- Выделяйте Value Objects для примитивов.
- Используйте Extract Method для длинных методов.
- Разделяйте God Object на несколько специализированных сервисов.
- Применяйте паттерны проектирования (Strategy, State, etc.).
